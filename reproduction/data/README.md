# Reproduction assets

`manifest.json` records the expected evaluation datasets, checkpoints, response archives, sizes, and SHA-256 values used by the paper-numbered notebooks.

The notebooks and inference utilities are available in this repository. The corresponding data and model archives are marked `coming-soon` until their public download locations are added.

The complete CAPTure CALDERA–Procmon snapshot is handled separately because it contains 499 CSV files and expands to approximately 822.44 GiB. It is not included in this repository. Its external download URL will be added to the website and manifest after hosting is finalized.
